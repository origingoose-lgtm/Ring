Запуск проекта

Требования

Установленный Unity Hub.

Версия Unity, 2022.3.62f2.

Инструкция по запуску

Скачайте или клонируйте репозиторий на компьютер.

Откройте Unity Hub.

Нажмите Add project from disk и выберите папку проекта.

Откройте проект в соответствующей версии Unity.

Дождитесь завершения импорта ресурсов.

В окне Project откройте стартовую сцену проекта.

Нажмите кнопку Play для запуска.

Сборка приложения

Откройте File → Build Profiles (в некоторых версиях Unity — File → Build Settings).

Добавьте необходимые сцены в список сцен сборки.

Выберите целевую платформу.

Нажмите Build и укажите папку для сохранения приложения.
